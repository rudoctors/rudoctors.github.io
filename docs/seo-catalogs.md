## Правила

1. Одна площадка — одна регистрация, без дублей.
2. Никаких PBN/покупных ссылок.
3. В отзывах/ответах — только факты каталога, без медицинских рекомендаций.
4. Отмечать результат в таблице: дата, ссылка, статус, URL.
