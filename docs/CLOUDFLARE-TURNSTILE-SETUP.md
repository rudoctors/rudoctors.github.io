# Настройка Cloudflare Turnstile для RuDoctors

## Зачем это нужно
Cloudflare Turnstile защищает форму отзывов (`/leave-review/`) от спам-ботов, DoS-атак и автоматизированных накруток.
В отличие от классической графической капчи (reCAPTCHA со светофорами/пешеходами):
- **95% пользователей не видят никаких проверок** — скрипт подтверждает человека в фоне за 0.5 сек.
- При подозрительном трафике появляется аккуратная галочка в один клик.
- Сервис полностью **бесплатен** и не имеет ограничений по объёму для стандартных сайтов.

---

## 1. Регистрация сайта в Cloudflare Turnstile

1. Войдите в консоль [Cloudflare Dashboard](https://dash.cloudflare.com/) (или создайте бесплатный аккаунт).
2. В левом боковом меню выберите **Turnstile**.
3. Нажмите кнопку **Add Site**:
   - **Site name:** `RuDoctors Reviews`
   - **Domain:** добавьте:
     - `rudoctors.com`
     - `www.rudoctors.com`
     - `localhost` *(для локальной разработки и тестов)*
   - **Widget Mode:** выберите **Managed** (рекомендуется) или **Non-interactive**.
4. Нажмите **Create**.
5. Скопируйте два ключа:
   - **Site Key** (публичный) — начинается с `0x...`
   - **Secret Key** (секретный) — начинается с `0x...`

---

## 2. Подключение ключей в проект

### А. Секретный ключ в Google Apps Script (Серверная проверка)
1. Откройте Google Таблицу **CRM Отзывы — Rudoctors** → меню **Расширения** → **Apps Script** (проект CRM отзывов).
2. В левой панели нажмите ⚙️ **Настройки проекта** (Project Settings).
3. В разделе **Свойства скрипта** (Script Properties) нажмите **Добавить свойство**:
   - **Имя (Property):** `CF_TURNSTILE_SECRET_KEY`
   - **Значение (Value):** ваш Secret Key из Cloudflare (начинается на `0x...`).
4. Нажмите **Сохранить свойства скрипта**.
5. Замените код скрипта на актуальный из `deno/gas_review_script.js` и обновите версию («Развернуть» → «Управление развёртываниями» → редактировать → Новая версия → Развернуть).

> [!NOTE]
> Если `CF_TURNSTILE_SECRET_KEY` не задан в Свойствах скрипта, Apps Script работает в режиме безопасного фоллбэка (пропускает форму без блокировки), продолжая отфильтровывать спам-ссылки.

### Б. Публичный ключ на сайте (Клиентский виджет)
1. **Для GitHub Pages (Production сборка):**
   - Перейдите в GitHub репозиторий `rudoctors/rudoctors.github.io` → **Settings** → **Secrets and variables** → **Actions** → вкладка **Variables**.
   - Нажмите **New repository variable**:
     - Name: `PUBLIC_TURNSTILE_SITEKEY`
     - Value: ваш Site Key из Cloudflare.
2. **Для локальной разработки:**
   - В файле `site/.env` добавьте строку:
     ```env
     PUBLIC_TURNSTILE_SITEKEY=0x4AAAAAA...
     ```

---

## 3. Встроенная защита от спам-ссылок (Defense in Depth)

Помимо проверки Turnstile, в Apps Script (`gas_review_script.js`) встроен автоматический контентный фильтр:
- Отзывы, содержащие ссылки (`http://`, `https://`, `t.me/`, `.ru/`, `.com/`) или ключевые слова спама (казино, крипта, ставки), **автоматически переводятся в статус «3. Отклонён»** с пометкой *«Автоматический спам-фильтр»*.
- Спам-отзывы **не отправляются в Telegram-чат модератора**, сохраняя чат чистым.
