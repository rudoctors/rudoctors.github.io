# Rudoctors — TikTok / Reels: готовые сценарии

Батч 1 (съёмка сегодня–завтра). Формат: вертикаль 9:16, 15–45 сек, озвучка + субтитры.  
CTA везде: **«ссылка в профиле» → rudoctors.github.io**  
Профиль: bio + Linktree/ссылка на сайт + TG-канал.

Как использовать:
1. Выбрать 1 сценарий → записать по «Озвучке» (или faceless: текст + AI-voice / свой VO).
2. Наложить B-roll: улицы Белграда, клиники снаружи, screen-recording сайта.
3. Субтитры крупно (CapCut auto-captions), хук на экран 0–1.5с.
4. Выложить на TikTok + Reels + Shorts + VK Клипы.
