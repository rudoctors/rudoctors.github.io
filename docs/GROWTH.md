# Rudoctors — Growth & Monetization

Дата: 2026-09-24  
Фокус: 30–90 дней → первый платящий размещённый профиль / рекламный пакет.

---

## 1. Кому продать (buyer personas)

### P1 — Врач с частной практикой (основной revenue)
**Кто:** русскоязычный врач в Сербии с приёмом: терапевты, педиатры, кардиологи, неврологи, эндокринологи, психиатры (уже есть в Sheets: Золотухо, Семенов, Голубев, Худякова, Авакянц, Бакулева…).  
**Боль:** «меня ищут русские пациенты, но я вижу только в Telegram/сарафане; нет стабильного потока».  
**Что продаём:**

| Пакет | Цена (целевая) | Что включает |
|---|---|---|
| Free | 0 | карточка, базовый рейтинг |
| **Featured** | **€30–50/мес** | приоритет в каталоге, фото, полное описание, ссылка на запись (без бейджа «Рекомендуем») |
| Pro | €80–120/мес | Featured + 1 «статья/пост» + аналитика кликов |
| Клиника | €150–300/мес | пакет на 3–5 врачей + логотип + баннер |

**Канал продажи:** личные сообщения в Telegram (админ `@leeloo70`-каналы), DM в Instagram, холодный аутрич визиток из Sheets (у 80% есть Telegram).  
**Сигнал успеха:** 1–2 оплаченных Featured до 15.12.2026.

### P2 — Клиника / медцентр
**Кто:** MediGroup, CITILAB, Doctorus Expert, AlfaMedStar, Vizim, BestMedica, Equilibrium, Tesla Medical, NIMCare (все уже в данных).  
**Боль:** привлечение русскоязычных пациентов без дорогого таргета.  
**Что продаём:** баннер на главной/каталоге (€100–250/мес), «клиника недели», спонсорский спецпроект («Гид по клиникам Белграда»).  
**Канал:** email/Telegram менеджерам клиник; у CITILAB/Alfa уже есть Telegram — warm lead.

### P3 — Медицинский туризм / релокация
**Кто:** компании по переезду в Сербию, insurance-брокеры, second-opinion сервисы.  
**Что:** affiliate за lead (€5–15/квалифицированный контакт) или баннер.  
**Приоритет:** P2/P3 после P1 (не распыляться).

### P4 — Реклама (traffic-dependent)
Google AdSense / спонсорские посты в Telegram — **после** стабильного трафика 3–5K UV/мес. Не раньше.

**Не продаём:** фейковые отзывы, paid ranking (только Featured ≠ подмена рейтинга).

Один снимается → режется на 4 платформы (CapCut).

### Tier 2 — Сообщества (недели 2–6)
- Facebook: expat Belgrade groups, «Русские в Сербии», «Сербия без обмана» — **полезные ответы**, не спам.
- Reddit r/serbia, r/belgrade — AMA «Russian-speaking doctors guide».
- forums.sr, local.ru — гайды со ссылкой.
- Яндекс.Директ/SEO: «врач русский Белград», «терапевт Белград русский» — позже, после 50 страниц SEO.

### Tier 3 — Partnership loops
- Клиники репостят «мы в рейтинге Rudoctors» → их пациенты видят.
- Каждый Featured-врач = амбассадор: кнопка «Поделиться» + UTM.
- Коллабы с RU-блогерами Белграда (еда/переезд) — barter: упоминание каталога за обзор.

### Вирусные механики (повторяются)
1. **Utility-листы:** «5 русских терапевтов в Белграде с записью» → сохранения/шеры.
2. **Сравнения:** «приём без страховки vs с полисом — цены 2026».
3. **Челлендж/серия:** «Найди врача за 60 секунд» screen-recording сайта.
4. **UGC:** пациенты рассказывают опыт → репост на Rudoctors (с оффером врачу).
5. **Geo-hook:** в каждом видео Белград/Нови-Сад в кадре или в тексте.

### Съёмка (бюджетно)
- **Формат:** talking head + B-roll (улицы Белграда, клиники снаружи, карта).  
- **Где:** согласие врача → кабинет/ординатория; иначе — фон Belgrade lifestyle.  
- **Кто говорит:** можно faceless (текст+voiceover), если врачи не светятся.  
- **Тексты:** готовим из карточек JSON (специальность, город, языки) — автогенерация черновиков.  
- **Частота:** 1 видео/день TikTok+Reels, 3–4/нед YouTube Shorts.  
- **Хештеги:** `#врачивсербии` `#белград` `#русскиеврачи` `#сербия` `#belgrade` `#expat` + локальные.  
- **Профиль:** bio → `rudoctors.github.io`, Link-in-bio (Beacons/Linktree → сайт, TG).
