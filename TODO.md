## 3. Модернизация приёма и модерации отзывов (Custom CRM)

**Проблема UX и конверсии:**  
Форма `/leave-review/` ранее перенаправляла пользователя исключительно на создание GitHub Issue (`github.com/rudoctors/rudoctors.github.io/issues/new`), что отсекало пациентов без профиля GitHub или при блокировке всплывающих окон.

**Внедрённое решение:**
1. **Этап 1 (Внедрено):** Интерактивная отправка через Telegram (прямой диалог с разработчиком `@balkandunav`, нативный шеринг `t.me/share/url`, кнопка копирования готового текста в буфер обмена) без принудительной авторизации на GitHub, с сохранением создания GitHub Issue как резервного канала. Внедрено и протестировано на живом сайте 01.11.2026.
2. **Этап 2 (Автоматизация через Webhook):** Интеграция с Google Apps Script / Telegram-ботом модерации для фонового сохранения заявок и кнопок одобрения.
