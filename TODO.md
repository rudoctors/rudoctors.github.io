## 3. Модернизация приёма и модерации отзывов (Custom CRM)

**Проблема UX и конверсии:**  
Форма `/leave-review/` сейчас перенаправляет пользователя на создание GitHub Issue (`github.com/rudoctors/rudoctors.github.io/issues/new`). Для обычного пациента необходимость регистрации и авторизации на GitHub является непреодолимым барьером, приводящим к потере до 95% потенциальных отзывов.

**Архитектурное решение (Custom CRM через Google Sheets + Telegram-бот):**
1. **Приём заявок:** Форма на сайте отправляет данные отзыва напрямую через лёгкий webhook / Google Apps Script в закрытую Google Таблицу (CRM-реестр отзывов).
2. **Модерация в Telegram:** В закрытый чат модерации / Telegram-бот мгновенно приходит уведомление с карточкой отзыва, оценкой и кнопками управления: `[Одобрить]` / `[Отклонить]`.
3. **Этап 1 (Текущее внедрение):** Интерактивная отправка через Telegram (прямой диалог с разработчиком `@balkandunav`, нативный шеринг `t.me/share/url`, кнопка копирования готового текста в буфер обмена) без принудительной авторизации на GitHub, с сохранением создания GitHub Issue как резервного канала. Внедрено и протестировано на живом сайте 01.11.2026.
4. **Этап 2 (Автоматизация через Webhook):** Интеграция с Google Apps Script / Telegram-ботом модерации для фонового сохранения заявок и кнопок одобрения.

*Статус:* Этап 1 внедрён (коммит `1fcaf28`). Подготовлен интерфейс для пользователей и разработчика.
